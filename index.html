Projects

Technova Hacker Badge

A custom NFC badge for the ~300 hackers at Technova, which I led the hardware design for in KiCad. It has a RISC-V microcontroller, tap-to-phone NFC check-in, an OLED screen, a D-pad, addressable LEDs and USB-C charging. I routed the double-sided board and put together the JLCPCB assembly order.

link to project

Submerge

An animated cyber/deep ocean koi theme for KDE Plasma 5 and 6, with around 1,290 downloads on the KDE Store across all versions. I wrote the GLSL shaders and a small water simulation for the ripples. There's also a live system HUD (CPU, GPU, memory, network, battery) and frame pacing that backs off to save power.

link to project

Physical Studio

Describe a hardware project and get an IKEA-style build guide for it, with a 3D model of every step and a photo check of each step on your real bench. I built an MCP server with CAD tools for part placement, wiring and collision/clearance checks, which exports GLB scenes to a React Three Fiber viewer. Deployed with Docker Compose on Vultr. Won Hack the Valley 11.

link to project

huddle

Lets several Claude Code agents on different machines work in the same repo at once. While one agent edits a file it is locked for the others, their copies go read-only and get its edits streamed in live. I wrote the relay server in plain Node.js with no dependencies and run it on Cloudflare Workers, with agent-to-agent chat, a web dashboard and git history sync between checkouts.

link to project

Schedule Share

Full-stack schedule-sharing platform for mutual availability — Firebase Auth/Firestore backend, real-time sync between friends, and an AI parsing step (Gemini API) that turns a screenshot of a schedule into calendar events automatically. Deployed on Vercel with cron-based cleanup, 20+ active users.

link to project

Bing Bang Dream Adventure

A Bad Apple! Rhythm game where you hit to notes using two IMU-based controllers that check your flick direction and timing. Pink for right, blue for left, and gold for bonus points. It can also be played with the ASD-JKL keys.
